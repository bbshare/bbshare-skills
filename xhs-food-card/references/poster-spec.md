# 海报版式规格（对齐 style-sample）

## 整体

- 竖版 3:4 社交海报
- 左 55% 摄影区 + 右 45% 奶油信息栏（可略有重叠指引线）
- 暖奶油 / 米白信息栏，深棕标题字，细线图标
- 氛围：窗光、纱帘、竹叶/绿植、亚麻布、陶瓷盘、木勺
- 气质：治愈、轻负担、茶饮店感、可发小红书

## 左侧

| 元素 | 规格 |
|------|------|
| 主标题 | 竖排大号衬线/书法感，深棕近黑，仅当前菜名 |
| 副标 | 竖排较小，`夏日××の××` |
| 红章 | 方印，2–4 字，如「夏日限定」 |
| 主视觉 | 高杯/碗居中偏下，分层清晰，可有冷凝水 |
| 前景 | 主料小碟（切块水果等）+ 木勺 |

## 右侧信息栏顺序（固定）

1. **食材搭配**（花形小标题）  
   4–5 行：圆盘图 + 名称 + 一行感官 + 约量  
   虚线从主视觉连到圆盘（可选）

2. **制作概要**  
   4 个圆形线性图标 + 短句，横向箭头连接

3. **风味特点**  
   1 段 1–2 句

4. **饮用建议** 或 **食用建议**  
   3 条，带小图标（雪花/杯子/调节）

5. **热量徽章**  
   大号 `约 N kcal/杯|份（估算）`  
   旁：`清爽低负担 夏日小确幸`

6. **脚注**  
   `*以上热量为估算值，具体以实际食材为准`

## 主视觉分层写法（Prompt 用）

按品类套用：

| 品类 | 建议呈现 |
|------|----------|
| 西米露/杨枝类 | 高杯分层：果泥底 → 椰奶 → 西米 → 顶果丁+薄荷 |
| 冰粉/凉粉 | 碗装透亮冻 + 糖水/水果/玫瑰 |
| 布丁/奶冻 | 玻璃杯凝固体 + 顶料 |
| 气泡饮 | 高杯液体 + 气泡 + 果肉/冰块 |
| 酸奶碗 | 俯侧 45° 碗，顶部整洁 topping |
| 沙冰 | 高杯刨冰质感 + 顶料 |
| 糖水 | 透明碗/杯，料点清晰 |

## 禁止

- 残留上一道菜的标题字
- 食材名与圆盘内容不符（如冰块写成椰浆图）
- 信息栏过密导致字体重叠
- 英文乱码标题
- 无「估算」的伪精确热量
