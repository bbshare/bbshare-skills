- 卡耐基开篇金句收束

### 片头（最重迭代区）

| 错法（用户打回） | 正法（终态） |
| --- | --- |
| CSS 灰多边形冒充玻璃 | 过曝光层 + **shards 炸开动效** |
| 贴爆款原片 video | **自建无字图** + HTML 蒙太奇 |
| 黑块/模糊遮烧录字 | 禁止；从源头无字 |
| 精细 3D 玻璃静帧 + 微推 | 转场感：bloom + 真动效 |
| 前几帧全白洗屏 | 压 base brightness / bloom / flash |
| 书卡 1.45s 才出、0.38s 同动画 | **1.05s 起**、~0.9s/本、**三动效交错** |
| 书卡只有图无 UI | 浮层书形 + 冰蓝书名 + 橙作者 |
| 纯黑 0.8s 接正片 | **hold + dissolve** |
| 参考片整段人声 | **Demucs no_vocals** + 本期女声 TTS |

用户原话级要点（写入 skill 的原因）：

1. 「只借鉴风格，**片头图自己做**，别遮爆款原片」  
2. 「玻璃要动、要像特效，别像展柜图」  
3. 「前几帧太白」  
4. 「书本浮层要早、要长、三种动画、可交错」  
5. 「@读书号 → @读书笔记」  

### 音频

有效：女声一次 TTS + Demucs glass SFX + BGM 0.09  

失败：贴 opener_bed 男声；合成噪点玻璃质感差；无 BGM  

### 正片

有效：2 场景雨巷/雨窗、硬切字幕、顶栏固定  

### 技术

- HyperFrames render：`render -o output/xxx.mp4 -q high`（不是 `--out`）  
- Node 24+；大字体 TTC 编译慢属正常  
- 浮层书卡与 brand 底图共用 src 可能 lint 警告 `duplicate_media_discovery_risk`  
- 书卡 3D 用 `transformPerspective: 1200`

## 《活着》文案迭代复盘（2026-08 · `huozhe-video`）

终态：旁白 **v4 密稿** · `output/huozhe.mp4`（~102s 含片头）+ 封面 + posting-copy。  
详见 `method.md`「说破 vs 疗愈」「A-短 / A-密」。

### 迭代轨迹（用户原话级）

| 版 | 钩子/主线 | 用户反馈 | 诊断 |
| --- | --- | --- | --- |
| v1 | 人不是为了有意义才活着 / 撑下去就是意义 | 「文案不太行」 | 哲学正确、钩子虚；金句复读 |
| v2 | 找不到意义，不丢人 / 不用交差 | 经 `/dbs-resonate` 改；仍「没共鸣、不想转」 | **疗愈腔**；点头不站队 |
| v3 | 熬过去不会有奖 / 只有下一天 | 钩子对了，但「像写诗、字太少」 | **电报诗/歌词体**；信息薄 |
| **v4** | 同 v3 硬核 + 铺垫/鸡汤对照/许可段 | **旁白通过 → 成片** | 说破频道 + **聊天密度** |

### 抽离规则（下次直接遵守）

1. **先频道后修辞**  
   - 先定「说破 / 反鸡汤 / 站队」还是「疗愈许可」；《活着》类冷硬书禁止默认疗愈钩子。  
   - 分享动机优先：**「我就说吧，鸡汤是假的」**，不是「谢谢你安慰我」。

2. **核心只留一条，禁止三连金句**  
   - v1/v2 同时砸「意义 / 呼吸 / 盼头 / 交差」= 全面正确、什么都没钉死。  
   - 终态只钉：**熬过去不会有奖（生活不颁奖）**；其余全是服务材料。

3. **钩子对标已成片断言，不对标「正确感悟」**  
   - 同构：完整一句、可截图、可对号入座。  
   - 弱：`不丢人` / `要接纳`；强：`不会有奖` / `越批评越改不了`。

4. **A-短 vs A-密**  
   - 默认可写 A-短；用户说像诗/太空/加字 → **整段加厚口播**，不要只把金句换词。  
   - 密稿结构：`等什么（假期待）→ 一刀拆穿 → 轻书锚 → 对照公共鸡汤 → 卸自我审判 → 收束许可`。  
   - 秒数跟语速走；v4 口播 ~98s + 片头 ≈ 102s **合法**。

5. **文案打回时接 dbs（若环境有）**  
   - 没戳中 → `dbs-resonate`；没转发欲 → `dbs-spread` + `dbs-hook`；像诗太空 → 加密度或换钩子池。  
   - 诊断必须落成 **下一版完整正文** 进 `narration-review.md`，再停旁白门。

6. **立场别滑成书评人**  
   - 弱：`是让你看见…` / `余华告诉我们…`  
   - 强：`不是要你励志，是卸掉那个包袱` / `把那层谎扯掉`

### 标题硬门（本片）

- ✅ 熬过去没有奖 / 活着无奖励  
- ❌ 泛化「看透人性」「苦难励志鸡汤」

### 制作侧附注（非文案但同集踩过）

- VO 片头静音：`adelay` alone 不够，需 **pad 到 BODY+3.56**（concat 静音或 `apad`）；`anullsrc` 未限长会失控拉长轨。  
- Whisper 近音：`发讲→发奖`、`服贵→福贵`、`鱼花→余华` 等，映射前先做 stream 替换。

## 样例线 B · 《活着》终态（2026-08 · `huozhe-sample-video`）

对标 `sample.mp4` 流程 + 用户迭代。完整规格：`visual-line-sample.md`。

### 用户原话级要点

1. 按 sample 做：毛笔两字、片头/画面质感、**1080×1440**、**中英字幕**  
2. 两字按书提炼 → **撑着**（不是随便形容词）  
3. 片头动画太少 → 补 **中缝裂口 + 光带 + 粒子 + 书卡 3D 三交错**  
4. 人物占满画面 → **≤约半屏高**；每镜 **动作不同**（远行/侧立/坐凳/迈步/仰脸）  
5. 首帧黑 → **封面烧录进 t=0**，再 dissolve 进毛笔  

### 技术坑

| 错 | 对 |
| --- | --- |
| runtime `background-clip` 毛笔字不可见 | Chrome 预渲染 `brush-chars.png` |
| `<video data-start>` 嵌在 timed section | 冻帧；改静帧 Ken Burns 或 video 做 stage 直接子级 |
| 黑幕 scaleY=1 开场 | 首帧 poster；或初始就半开 |
| 出图 prompt 写「小一点」仍半身特写 | `extreme wide` + `20–40% frame height` + **读图返工** |
| 五镜同一 Ken Burns | 每镜不同 from/to |

### 时间轴摘要

```text
0–0.45    first-frame 封面烧录
0–2.7     撑着 + 天空裂口 + 钩子中英
2.55–6.3  书封 3D 轮播
6.1–42.6  五镜山水 + 中英字幕（VO 从 0 起）
```

### 与听页线关系

- 文案方法共用（说破、A-密、删书名测试）  
- 片头/正片/字幕 **两套模板**，一集只选一  
- 导出包相同；线 B **多验第 0 帧**
