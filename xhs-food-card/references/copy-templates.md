# 小情绪文案模板

## 标题公式

1. `38℃的夏天，靠这杯{名}续命{emoji}`
2. `低卡夏日小确幸｜约{N}kcal 的{名}`
3. `懒人{分钟}分钟｜比奶茶更{卖点}的{名}`
4. `茶饮店同款复刻｜家里也能做的{名}`
5. `空调房快乐水上线｜{名}`
6. `{痛点}的日子里，请收下这杯{名}`

## 正文骨架

```
{场景钩子：天气/加班/宅家/想喝奶茶}

{降低门槛：几步/几分钟/不用烤箱}

第一口是{味道A}，
第二口是{味道B}，
{口感彩蛋：Q弹/冰沙化开/奶盖咸甜…}

{情绪落点：小确幸/允许懒/和分享的人}

约 {N} kcal，{负担感一句}。
留给{人群一句} {emoji}
```

## 开场钩子库

- 热成狗的日子里，不需要太复杂的治愈
- 又想喝奶茶又怕负担的下午
- 打开冰箱只有水果和一罐椰浆的时候
- 茶饮店排队 40 分钟？今天在家 10 分钟搞定
- 空调房 + 一部剧 + 这一杯，夏天就够了

## 情绪落点库

- 有时候快乐就是一杯冰到发麻的小甜水
- 认真生活，也认真偷懒
- 把夏日份的糖分，花在看得见的果肉上
- 不是放纵，是给自己的季节限定奖励
- 和愿意分享的人，味道会更好一点

## 标签组合

基础：`#夏日小零食 #{菜名无空格} #低卡甜品 #夏日解暑 #懒人甜品 #小红书美食`

按品类追加：

| 品类 | 追加 |
|------|------|
| 西米/芋圆 | `#西米露 #椰奶控` |
| 冰粉凉粉 | `#冰粉 #古早味` |
| 气泡 | `#快乐水 #气泡水` |
| 冻品布丁 | `#冰箱甜品 #隔夜甜品` |
| 糖水 | `#广式糖水 #清热解暑` |
| 酸奶碗 | `#轻食早餐 #酸奶碗` |

## 互动句（文末可选 1 句）

- 你更喜欢水果多一点，还是椰奶多一点？
- 评论区扣「配方」我发详细克数版
- 下一杯想看我做什么？留言我排期
