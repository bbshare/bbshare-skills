# Series Opener（系列片头 — 自建对标爆款）

> 参考实现：`renxingderuodian-video`（2026-07 迭代终态）  
> **本文 = 视觉线 A（听页玻璃 + 浮层书卡）。**  
> 视觉线 B（毛笔两字 + 书封轮播 + 首帧封面）→ **`visual-line-sample.md`**，勿与本文混用。

## 爆款结构（对标，不抄原片）

约 **0–2.6s** 固定系列蒙太奇（四支爆款共用结构，只换后半本期）：

| 时间 | 画面 |
| ---: | --- |
| 0–0.85 | **过曝光碎玻璃转场**（动效，不是静帧海报） |
| 0.85–1.05 | **半遮挡人像/揭开**（可选，宜短） |
| 1.05–2.6 | **3 本浮层书卡**交错出现（书名+作者 UI） |
| 2.55+ | hold 末帧 → dissolve 进本期主视觉 + 顶栏本期书名 |

## 硬门（迭代踩坑后写死）

### 1. 画面必须自建

| 禁止 | 正确 |
| --- | --- |
| 贴爆款原片 `<video>` 当片头 | AI 生成 **无字** 静帧 + HTML 蒙太奇 |
| 黑块/模糊遮烧录字幕 | 从一开始就不要烧录字 |
| CSS 深灰多边形冒充玻璃 | 过曝光层 + 碎片炸开动效 |

### 2. 玻璃 = 转场特效，不是 3D 产品图

用户反馈「精细碎片静帧 + 微推」不如爆款「冲」：

- 爆款：大块半透明、**高光 bloom**、几乎过曝、在**动**
- 失败：细节过实、彩虹色散过细、整屏过白

**推荐实现：**

```text
#op-glass
  glass-base   黑底碎玻璃图（brightness 约 0.9，忌纯白底图）
  glass-layer  软光 screen，opacity 峰值 ≤0.3
  glass-bloom  径向白光，起始 opacity 很低，中段再起
  glass-flash  白闪 ≤0.15，勿开场 0.8+
  .gshard ×10  GSAP 从中心炸开 + 旋转 + 淡出
```

- 玻璃段约 **0.8–1.0s**
- 前几帧**不能一片白**（压 brightness / bloom / flash）
- 预览必须看动效，静帧 contact sheet 看不出炸开

### 3. 人像揭开（可选，宜短）

- 宜：**半遮挡**（手/纸/缝）、留白、悬念
- 忌：正脸铺满 + 过度戏剧（像封面海报）
- 时长约 **0.25–0.35s** 即可

### 4. 浮层书卡（系列感核心）

用户明确要求：2–3 本「书本样子」浮层 + 书名 + **不同动画** + **交错**。

**时间（推荐）**

| 书卡 | start | 入场 | 停留 | 出场 | 动画性格 |
| --- | ---: | ---: | ---: | ---: | --- |
| 书1 | **1.05** | 0.32–0.36s | **≥0.65s** | 0.26–0.30s | 从左滑入 + 侧倾 |
| 书2 | **1.55** | 0.34–0.38s | **≥0.65s** | 0.26–0.30s | 从右翻入 + back.out |
| 书3 | **2.05** | 0.36–0.40s | **≥0.65s** | 0.26–0.30s | 从下升起 + bounce |

- 总可见约 **0.9–1.0s/本**（入+停+出）
- 交错约 **0.45–0.55s**（上一本未完下一本进）
- **禁止**三本同一动画、每本 <0.4s、1.45s 才出现

**书卡 UI（对标听页顶栏气质）**

```text
.float-book-inner
  封面图（无字）
  书脊阴影 + 白描边 + 大投影（看得出是「一本书」）
  .fb-title   白/冰蓝 + 黑描边 + 冰蓝 glow
  .fb-author  橙色纯字（无 pill 框）
```

书名可用账号固定资产（例：《罪与罚》《自在独行》《我与地坛》），与本期书名不同。  
本期《书名》顶栏从 **hold 开始**再出现。

### 5. 开场字幕必须「两拍」（罗生门硬门）

| 错 | 对 |
| --- | --- |
| 字幕一次出「今天分享的是，《书名》」 | 先 **「今天分享的是」**，口播书名时再出 **「《书名》」** |
| TTS 写成一行带书名 | TTS 拆两行：`今天分享的是。` / `《书名》。`（中间有气口） |
| 顶栏书名与中字书名同秒叠出 | 中字点题后，顶栏再稳上（或气口后再上） |

- 用正片同一套 **`.zh.tight`**
- 中字 `《书名》` 与书卡蒙太奇可同段（片头将结束时）
- 字幕层 **z-index 高于书卡**；禁止为躲书卡拖后字幕

### 6. 片头 → 正片衔接

**禁止 0.5s+ 纯黑死场。**  
**推荐**：书名口播后有 **~0.4–0.8s 画面 hold 气口** 再 dissolve 进正片（贴 TTS 静音）。

```text
~2.0–2.7   口播《书名》+ 中字点题；书卡收尾
~2.6–3.1   hold 停顿（仅顶栏/水印，不抢钩子）
~3.1–3.6   hold → 正片 dissolve
~3.1+      钩子字幕跟 Whisper 时间
```

停顿感来自 **旁白气口 + hold**，不是长黑屏。

### 7. 音频

见 `audio-bgm.md`：

```text
master = 本期 TTS（一次录完） + Demucs 去人声后的 glass SFX + 弱 BGM
```

**禁止**整段贴爆款人声床（男声串戏）。

默认使用无口播片头：`0–3.56s` 只播放 glass/SFX + BGM，正式旁白从 `3.56s` 开始。旁白一旦延迟，正片场景和字幕 cue 也必须同步后移 `3.56s`。只有用户明确要固定口播时，才使用「今天分享的是 → 《书名》」两拍。

## HyperFrames 结构示意

```html
<!-- glass scene: multi-layer + .gshard -->
<!-- face scene -->
<!-- brand BG scenes (较长，垫在书卡下) -->
<!-- #opener-caption-ui  今天分享的是… -->
<!-- #opener-books-ui    #fb1 #fb2 #fb3 浮层书卡 -->
<!-- #scene-hold -->
<!-- #scene-a / #scene-b 正片 -->
<!-- #series-title  #watermark  从 hold 起显示 -->
```

- 各 clip **不同 `data-track-index`**，时间不重叠同轨
- 书卡是 **UI 浮层**（`data-layout-ignore`），不是独立 clip
- GSAP：`transformPerspective: 1200`；书卡 tween 用 `overwrite: "auto"`
- 浮层书卡与 brand 底图若共用同一 `src`，可能触发 `duplicate_media_discovery_risk` 警告；可接受或给书卡用裁切副本文件名

## 验收

- [ ] 玻璃在动、够亮但不洗白
- [ ] 书卡 ≥1.05s 出场，每本停留够长，动画三种不同
- [ ] 书卡有书形（脊/边/影）+ 冰蓝书名 + 橙作者
- [ ] 字幕与正片同系统，无黑底遮挡
- [ ] 人声只有本期 TTS；有 glass SFX + BGM
- [ ] hold → dissolve，无黑洞断层

## 反模式速查

| 错 | 对 |
| --- | --- |
| 爆款原片 + 黑块遮字 | 自建无字图 + 浮层 UI |
| 精细 3D 玻璃静帧 | 过曝转场 + 碎片炸开 |
| 前几帧全白 | 压 brightness / bloom / flash |
| 书卡 0.38s 同动画 | 0.9s+、三动效、交错 |
| 书卡只有图无字 | 必须顶栏书名+作者 |
| 纯黑 0.8s 接正片 | hold + dissolve |
| 参考片男声床 | Demucs no_vocals 或干净 SFX |
