## 一句话

**不是书评，是借书名的人生许可证。**

## 规格

| 项 | 值 |
| --- | --- |
| 画幅 | 3:4，`1080x1440`（参考片多为 576×768 压缩源） |
| 时长 | **31–35s** 甜蜜点；Mode A 硬上限 40s |
| 响度 | 参考约 -13 LUFS、LRA≈2；制作目标 **-14 LUFS / -1 dBTP** |
| 音频 | **全程有 BGM**，几乎无静音空场 |
| 片头 | 碎玻璃/碎片动画 +「今天分享的是…」（约 0–2.8s） |
| UI | 顶书名（蓝白描边发光）+ 橙作者行；底水印；中下大字幕 |
| 视觉线 B | 可选：毛笔两字 + 中英字幕 + 山水半屏人物（见 `visual-line-sample.md`） |

## 文案公式（Mode A）

```
[口播片头] 今天分享的是，《书名》。
[钩子] 一句刺痛现实的断言（可删书名仍想转发）
[展开] 3–6 句短句，每句约 4–14 字
[金句] 一句可截图收束
[可选] 极短互动（不靠问答撑爆）
```

### 爆款钩子特征

- 恋爱痛：`靠近你就靠近了痛苦`
- 边界：`我没有那么多人需要去取悦`
- 成人：`父母都无法兜底的人生`
- 病痛：肉身/精神分裂、`又无大悲`
- 反鸡汤/忍耐：`熬过去，不会有奖。只有下一天`（《活着》终态）

钩子必须是 **一句完整可截图断言**。  
频道默认 **说破/站队**，不是「不丢人」式疗愈许可（见 `method.md`）。

### 禁止

- 百科三点、首先其次
- 长情节复述
- 先铺垫半天才亮观点
- 只有「这本书讲了…」没有情绪许可
- **三套金句换皮复读**同一结论（全面正确 = 没钉死）
- **电报诗当密稿**：用户要字数时加场景/对照/轻锚，不要只加空行

## 画面公式

- **1–2 张**情绪静帧 + 慢推/微移 + 粒子（雨、落叶、光尘）
- 情绪色匹配主题（雨夜=痛，暖油画=爱，雪山=清醒，湖山=自渡）
- 不字面插画
- 硬切主要在片头；主体少切、稳

## 声音公式

- 慢语速、小起伏、贴耳
- **BGM 必须铺满**（参考片不是干声）
- 重压缩、信息流里「听得见」

## 与旧版错位（不要退回去）

| 旧（弱） | 新（对标爆款） |
| --- | --- |
| 多场景情节板 | 1–2 情绪场 |
| 议论文五段 | 歌词式短句 |
| 无 BGM / BGM 极弱可忽略 | 强制混 BGM |
| 45s+ 讲透 | 31–36s 刺中 |
| 评论区提问收尾 | 金句收尾优先 |
