# Visual Sourcing Decision Tree

Agent 自行判断。不要问用户「要不要用素材库」。

**先选视觉线**：听页线 A（下文章节） vs 样例线 B（`visual-line-sample.md` 全文）。

## 线 B 速查（样例线）

- 同角 `char-ref` → 5 镜 `image_edit`  
- 人物 **≤约半屏高**，动作镜间必须不同  
- 出图后 **read 图验收** 占比；不合格重出  
- 详见 `visual-line-sample.md`

## Mode A / 线 A（默认）：情绪场优先

目标：**1–2 张**主视觉撑满 30s+，不是分镜剧情板。

```
旁白情绪主线
    │
    ├─ 定情绪色（雨夜冷 / 暖油画 / 雪山清 / 湖山亮 / 室内烛…）
    │
    ├─ 1 张主静帧能否撑全片？
    │     └─ YES → 单图 + 慢 Ken Burns + 粒子/雾层
    │
    ├─ 需要情绪递进？
    │     └─ 第 2 张同世界微变（略亮/略远/换角度），中段切一次
    │
    └─ 禁止默认 6–8 张情节分镜
```

### 情绪色速查

| 主题 | 画面倾向 |
| --- | --- |
| 痛、病、死、悔 | 雨夜街、湿窗、冷灯 |
| 爱而不得 | 暖色油画街/水城、霓虹倒影 |
| 边界、屏蔽、清醒 | 雪山、路牌、开阔白天 |
| 孤独自渡 | 湖栈道、独行背影、晴天 |
| 批评、面子、人际（《人性的弱点》） | 空走廊、窗边独影、冷静办公室一角、雨窗——**不要**群嘲/吵架字面 |

### 字面插画禁令（Mode A）

- 「批评」≠ 两人指着鼻子骂  
- 「窄门」≠ 必须画门  
- 「屏蔽」≠ 防火墙 UI  

画面承载**情绪**，字幕承载**论点**。

## Mode B：语义镜头

```
旁白场景语义
    │
    ├─ 明确情节动作？ → AI 定制竖图（写清动作量级）
    ├─ 需要环境动感？ → 素材库视频背景
    └─ 仅情绪？ → 同 Mode A
```

## AI 生成

- 竖构图，无字无 Logo，不露清晰正脸  
- 一图一情绪，2–5 句自然语言  
- 生成后目视检查 → `sips -z 1440 1080` → `assets/generated/`  
- 登记 `docs/asset_sources.md`
